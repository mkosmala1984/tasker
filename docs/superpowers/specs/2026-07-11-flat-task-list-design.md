# Flat Task List Design

## Scope

Replace the Today active-task cards with a full-width flat list. Rows have no gap, side margin, rounded corners, or individual card shadow. A subtle bottom border separates adjacent rows, and the last row has no separator.

## Behavior

Task actions, keyboard focus, expansion, completion, postponement, and task details remain unchanged. The change is limited to presentation classes in the Today active-task list.

## Responsive behavior

Existing responsive action wrapping and minimum button hit areas remain in force. Rows continue to use the available width at every viewport size.
